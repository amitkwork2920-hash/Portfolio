# API Gateway Vendor Selection Decision Enabler

A structured, automated Excel-based selection calculator built to accelerate your API management platform building journey. This tool helps organizations evaluate vendors.

## 🛠️ Problem 

* 📐 [What?](./images/problem.jpg)
* 📊 [How?](./images/solution.jpg)

## 🚀 Key Features

* **API Gateway Vendor Assessment:** Evaluates different API Gateway vendors (Apigee, Kong, Tyk, WSO2) on the below parameters :

|Parameters|
   |-|
   |**Scalability & Performance**|
   |**Integration & Ecosystem**|
   |**Security & Compliance**|
   |**Ease of Use & Administration**|
   |**Community & Support**|
   |**Cost & Licensing**|
   |**Extensibility & Customization**|
   |**API Documentation & Developer Experience**|
   |**Multi-Cloud & Hybrid Deployment Support**|
   |**Analytics & Reporting**| 
   |**Lifecycle Management & Governance**|
   |**TLS Management**|
   |**High Availability**|
   |**Traffic Management**|
   |**API Caching**|
   |**Rate Limiting**|
   |**Failover & Resilience**|
