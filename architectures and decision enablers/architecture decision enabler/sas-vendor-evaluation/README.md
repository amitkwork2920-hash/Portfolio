# Mainframe SAS (Statistical Analytic Systems platform) Vendor Selection Decision Enabler

A structured, automated Excel-based selection calculator built to accelerate your legacy SAS (Statistical Analytic Systems) replacement building journey. This tool helps organizations evaluate vendors.

* 📐 [What?](./images/problem.jpg)

## 🚀 Key Features

* **SAS (Statistical Analytic Systems):** Evaluates different ESB vendors (DSW, SAS Viya, Databricks, IBM Watson, SnowFlake, AWS AI/ML, Azure AI/ML, GCP AI/ML) on the below parameters :

|Parameters|
   |-|
   |**Core Data Science, ML Lifecycle & Infra Framework**|
   |**Polyglot Language Runtime & Compilers**|
   |**Legacy SAS Compatibility & Migration Pathways**|
   |**Automated Operations, MLOps & Model Serving**|
   |**Data Architecture, Governance & Mesh Fabric**|
   |*UI Workspace UX, Usability & Collaboration**|
   |**Vendor Support Ecosystem, SLAs & Advanced Guardrails**|
   |**Reliability & Fault Tolerance**|
   |**Monitoring & Management**|
   |**Vendor Lock-in & Portability**| 
   |**Deep Mathematical Parity & High-Stakes MLOps**|
