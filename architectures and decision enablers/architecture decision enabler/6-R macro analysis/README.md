# 6-R Macro (pre-TCO) analysis Decision Enabler

A structured, automated Excel-based selection calculator built to accelerate your migrate to cloud or not journey. This tool helps organizations make the decision to migrate 
an application to cloud or replace, refactor, rearchitect.

## 🛠️ Problem 

* 📐 [What?](./images/problem.jpg)
* 📊 [How?](./images/solution.jpg)

## 🚀 Key Features

* **6-R Macro (pre-TCO) analysis :** Decides by evaluating through 40 point (15 parameters) whether to migrate an application to cloud or refactor or replace or rearchitect:

|Parameters|
   |-|
   |**Architecture**|
   |**Compliance**|
   |**Hosting & Network**|
   |**Integration**|
   |**Licensing**|
   |**Usage**|
   |**Resilience**|
   |**Direct Operational Costs**|
   |**Potential Cost**|
   |**Reuse**| 
   |**Standardization**|
   |**Agility**|
   |**End User Satisfaction**|
   |**Financial**|
   |**Risk**|
